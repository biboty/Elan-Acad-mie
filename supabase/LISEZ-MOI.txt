Élan Académie — mise en route de l'application (espace parents, animateurs, administration)

L'application est dans le dossier app/ du site (adresse : .../app/). Elle a besoin d'une base de données
Supabase (gratuite au lancement). Six étapes, environ 15 minutes, une seule fois.

1. CRÉER LE PROJET
   - supabase.com > Start your project > compte gratuit (avec l'e-mail dédié de l'académie).
   - New project : nom « elan-academie », région « West EU (Frankfurt) » ou « West EU (Paris) »,
     mot de passe de base de données : généré, rangé dans le gestionnaire de mots de passe.
   - Attendre 1 à 2 minutes que le projet soit prêt.

2. CRÉER LES TABLES ET LES DROITS
   - Menu de gauche > SQL Editor > New query.
   - Coller tout le contenu du fichier supabase/schema.sql, puis Run. Le message doit être « Success ».
   - Ce script peut être rejoué sans risque si on le modifie plus tard.

3. RÉGLER LA CONNEXION
   - Authentication > Providers > Email : laisser activé. Désactiver « Confirm email » pour le lancement
     (sinon chaque parent doit cliquer dans un e-mail, et l'envoi d'e-mails gratuit de Supabase est limité
     à quelques messages par heure). On le réactivera avec un service d'e-mail dédié.
   - Authentication > URL Configuration :
       Site URL : https://biboty.github.io/Elan-Acad-mie/app/
       Redirect URLs : ajouter la même adresse (et plus tard https://elanacademie.ma/app/).

4. RÉCUPÉRER LES DEUX CLÉS
   - Project Settings > API : copier « Project URL » et la clé « anon public ».
   - Les envoyer à Claude (ou les coller soi-même dans app/config.js : supabaseUrl et supabaseAnonKey).
     Cette clé est publique par conception : la sécurité vient des règles de la base, pas de son secret.

5. CRÉER LE COMPTE ADMINISTRATEUR
   - Authentication > Users > Add user > Create new user : bibotyassine4@gmail.com, mot de passe, « Auto confirm user ».
   - Revenir dans SQL Editor et exécuter :
       update public.profiles set role = 'admin' where lower(email) = lower('bibotyassine4@gmail.com');
   - Recharger l'application : le rôle « Administration » apparaît en haut à droite.

6. PREMIERS RÉGLAGES DANS L'APPLICATION
   - Groupes : créer « Bâtisseurs samedi » et « Argumentateurs mercredi ».
   - Équipe : quand un animateur a créé son compte, lui donner le rôle « Animateur », puis l'attribuer à un groupe.
   - Familles : saisir les premières familles (ou « Créer la famille » depuis la liste d'attente).
   - Les familles ne créent pas de compte (décision du 26 octobre, inscriptions désactivées dans Authentication >
     Sign In / Providers > « Allow new users to sign up »). Vous créez chaque accès dans Authentication > Users >
     Add user > Create new user (e-mail de la fiche famille, mot de passe provisoire, « Auto confirm user »), puis
     vous l'envoyez au parent sur WhatsApp ; il change le mot de passe dans « Mon compte ». Le compte est relié
     automatiquement à sa famille quand l'e-mail correspond.

CE QUE FAIT CHAQUE RÔLE
   Administration : liste d'attente (alimentée par le formulaire du site), familles, enfants, groupes, séances,
                    retours mensuels, rencontres métiers, équipe et comptes.
   Animateur      : séance du jour (présences, notes), ses enfants (fiche, projets, badges), retours mensuels.
   Parent         : ses enfants (séances faites et restantes, projets, badges, retours mensuels, présences),
                    rencontres métiers, son compte.

PLUS TARD
   - E-mails (confirmation, mot de passe oublié) : Authentication > SMTP Settings avec un service comme Resend
     (gratuit jusqu'à 3 000 e-mails par mois), puis réactiver « Confirm email ».
   - Sauvegardes : Supabase garde des sauvegardes quotidiennes 7 jours sur le plan gratuit ; Database > Backups.
   - Domaine : quand elanacademie.ma est en place, ajouter https://elanacademie.ma/app/ dans Redirect URLs.

7. COURS EN LIGNE ET NOTES PENDANT LE COURS (ajouté le 26 octobre 2026)
   - Base déjà créée avant cette date : exécuter une fois supabase/migration-2026-10-26-visio.sql dans SQL Editor
     (fait le 26 octobre sur le projet actuel). Une base neuve n'en a pas besoin, schema.sql contient tout.
   - Groupes : le champ « Lien de visio permanent » (Google Meet, Zoom, Jitsi) est repris sur chaque séance du groupe.
   - Séances > « Planifier une séance » : groupe, date, heure, lien. « Créer une salle » génère une salle Jitsi
     gratuite (meet.jit.si) ; la première personne qui entre, l'animateur, se connecte avec un compte Google ou
     GitHub pour devenir modérateur ; les familles entrent sans compte.
   - Salle de classe (une séance) : « Lancer le cours » ouvre la visio dans un nouvel onglet (ou dans la page pour
     Jitsi), les notes pendant le cours s'enregistrent toutes seules en écrivant (équipe seulement), les présences
     et la note par enfant s'enregistrent à chaque clic, le « Résumé pour les familles » est visible par les parents.
   - Espace parents : carte « Prochaine séance » avec le bouton « Rejoindre le cours » quand la séance est en ligne.

8. INSTALLER L'APPLICATION SUR UN TÉLÉPHONE (ajouté le 26 octobre 2026)
   - L'application est une « PWA » : sur Android (Chrome), ouvrir .../app/ puis menu ⋮ > « Installer l'application » ;
     sur iPhone (Safari), bouton Partager > « Sur l'écran d'accueil ». Icône « Élan » sur fond indigo, plein écran.
   - Fichiers : app/manifest.webmanifest (nom, couleurs, icônes), app/sw.js (réseau d'abord, jamais de vieille version),
     app/icons/ (192, 512, maskable, Apple).
   - Play Store : possible à partir de cette PWA (outil PWABuilder, compte développeur 25 USD une fois, test fermé
     12 testeurs pendant 14 jours pour un compte personnel). App Store : 99 USD/an, un Mac, et Apple refuse les
     simples sites emballés : à faire en V2 avec des fonctions natives (notifications).

9. RÉSERVATION DE SÉANCES AVEC UN ANIMATEUR, PLANNING (ajouté le 26 octobre 2026)
   - Base déjà créée avant cette date : exécuter une fois supabase/migration-2026-10-26-reservations.sql (fait le 26 octobre).
   - Animateur (et administrateur) : Mon compte > « Ma fiche » (matières, présentation), puis Mes créneaux > Publier un
     créneau : date et heure, durée, type (séance d'essai, individuelle, rattrapage), matière, places (1 à 8), en ligne
     ou en présentiel, lien de visio (« Créer une salle » pour une salle Jitsi), note visible par les familles.
     Il voit qui a réservé (prénom, parent, WhatsApp), lance la visio, écrit un mot aux parents après la séance.
   - Parent : Réserver > choisit l'animateur et le créneau > Réserver : confirmé tout de suite si une place reste et si
     le créneau n'est pas passé (la base vérifie). Annulation possible jusqu'à l'heure de la séance.
   - Parent : Planning = séances de groupe + séances réservées, jour par jour, bouton « Rejoindre » quand c'est en ligne.

10. PAIEMENTS, SOLDES ET RÉMUNÉRATION DES ANIMATEURS (ajouté le 26 octobre 2026)
   - Base déjà créée avant cette date : exécuter une fois supabase/migration-2026-10-26-paiements.sql (fait le 26 octobre).
   - Les familles paient directement (espèces, virement). Administration > Paiements > « Enregistrer un paiement » :
     famille, enfant (facultatif), montant, date, mode. Le solde = versements − séances consommées, calculé tout seul :
     chaque présence à une séance de groupe (tarif par séance) et chaque séance réservée passée (tarif par heure,
     au prorata). Une réservation marquée « absent » n'est ni facturée ni rémunérée.
   - Catalogue des prestations (onglet Paiements, en bas) : par prestation, ce que paie la famille et ce que reçoit
     l'animateur, par heure ou par séance. Vous ajoutez vos propres prestations (matières, niveaux). Valeurs de départ
     à ajuster. Tarif négocié pour un enfant : fiche de l'enfant > « Tarifs de l'enfant ».
   - Animateur > Mon solde : ce que l'académie lui doit, mois par mois, séance par séance. Il ne voit jamais les
     versements des familles ni les tarifs payés : la base ne les lui montre pas.
   - Parent > Paiements : son solde, ses versements, ses séances consommées, les tarifs.

11. CATALOGUE, TARIF PAR ENFANT, RECRUTEMENT (ajouté le 26 octobre 2026, soir)
   - Base déjà créée avant : exécuter une fois supabase/migration-2026-10-26-catalogue-recrutement.sql (fait le 26 octobre).
   - Catalogue : chaque groupe, chaque créneau et chaque rencontre métiers pointe vers une prestation du catalogue
     (sinon la prestation par défaut de son type). Une rencontre n'est facturée que si « Facturer » est coché.
   - Recrutement : le lien du test est .../candidature.html (bouton « Copier le lien du test » dans l'onglet Recrutement).
     Le candidat remplit ses coordonnées, passe un QCM de 10 questions tirées au sort dans sa matière et son niveau,
     enregistre une vidéo de présentation (3 min) puis une vidéo de situation (4 min, une erreur d'élève à repérer),
     depuis son navigateur (ou colle un lien). Les vidéos vont dans le bucket privé « candidatures » (80 Mo maximum
     par vidéo), lisibles par l'administration seulement. Onglet Recrutement : candidatures à évaluer, QCM corrigé,
     vidéos, décision (Retenir / Refuser), suppression. « Questions et situations » : ajouter ou modifier le QCM.
     Un candidat retenu reçoit son accès comme un animateur (Supabase > Users > Add user, puis rôle dans Équipe).
   - Deux candidatures « Test automatique » ont servi à vérifier l'installation : à supprimer depuis l'onglet Recrutement.

12. SAUVEGARDE, RAPPELS, DEVOIRS, DOCUMENTS SIGNÉS (ajouté le 26 octobre 2026, nuit)
   - Base déjà créée avant : exécuter une fois supabase/migration-2026-10-26-rappels-devoirs.sql (fait le 26 octobre).
   - Sauvegarde : Tableau de bord > « Télécharger la sauvegarde » : un fichier zip (un CSV par table + le tout en JSON),
     à ranger dans votre Drive ou sur l'ordinateur. Le tableau de bord passe en orange après 7 jours sans sauvegarde.
     Le plan gratuit de Supabase ne fait aucune sauvegarde : faites-la chaque semaine. Restauration : Table Editor >
     la table > Insert > Import data from CSV.
   - Rappels : Tableau de bord > « À prévenir aujourd'hui » : séances et réservations de demain, absences du jour,
     soldes négatifs, chaque ligne avec un bouton WhatsApp au message déjà rempli. Les animateurs ont la même carte
     dans « Mes séances » pour leurs familles.
   - Devoirs : salle de classe > « Devoirs pour la prochaine séance » (et dans un créneau, après la séance). Les
     familles les voient dans « Mes enfants » avec une case « fait ».
   - Documents signés : fiche famille > protocole d'accueil, autorisation photo (ou refus), règlement, avec la date.
     Pastille « Documents n/3 » dans la liste des familles ; compteur des inscrits sans protocole dans le tableau de bord.
