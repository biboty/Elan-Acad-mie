Site web et application d'Élan Académie — académie pour les 7-18 ans à Casablanca.

- Site statique : ouvrir index.html. Publié avec GitHub Pages (source dans source/build.py).
- Application (app/) : espace parents, animateurs et administration, base Supabase (voir supabase/LISEZ-MOI.txt).
  Suivi des séances faites et restantes, projets, badges, retours mensuels, rencontres métiers,
  salle de classe en ligne (visio lancée depuis l'application, notes pendant le cours, présences).
